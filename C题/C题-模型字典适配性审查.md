## 2. 题目与数据结构识别

| 维度 | 识别结果 |
|---|---|
| 数学任务 | **优化 / 决策**：在满足供电可靠性与储能物理约束的前提下，最小化购电费用；问题 2–4 进一步为**不确定性下的序贯决策** |
| 观测单元 | **10 分钟时段**（每天 144 段），聚合到 4 小时段（表 2）与整点（附件 3 预报） |
| 决策变量 | 计划购电量 $P_t$、充电量 $C_t$、放电量 $D_t$、弃光量 $Q_t$、紧急购电量 $E_t$、调整购电量 $A_t$ |
| 状态变量 | 储电量 $S_t$（**跨时段、跨日耦合**） |
| 目标 | 全天 / 全年总购电费用（元），由计划费 + 紧急费（5×）+ 偏差费（0.5×/1.5×）构成 |
| 数据类型 | 连续数值（功率 kW、电价 元/kWh、电量 kWh）；时间序列（日内 + 季节性 + 年度） |
| 依赖性 | **强**：①SOC 递推造成时段间强耦合；②同一天 144 段非独立；③相邻日通过 SOC 耦合；④预报误差存在日内时间相关 |
| 样本量 | 附件 2/4：365 天 × 144 段 = **52 560** 个观测/变量；附件 3：1460 条 × 24 整点；结果期 334 天 |
| 缺失与异常 | **无缺失**（实测负载与光伏 52 560 个观测全部有值）；无负功率；**无负电价**（附件 4 最低 0.0076 元/kWh） |
| 不平衡性 | 结构性零显著：夜间光伏恒为 0；光伏 > 0 的时段在典型日仅 89/144 |
| 时间结构 | 明确的日内周期（夜间低谷 / 正午光伏峰 / 晚高峰）与季节周期（春分—夏至—秋分—冬至） |
| 硬约束 | $S_t\in[1200,10800]$ kWh；$C_t,D_t\le 833.33$ kWh/段；供电 ≥ 负载；问题 1 的 $S_0=S_{144}$ |
| 期望输出 | 可执行的逐时段操作表（5 个 xlsx），不是概率、不是分类、不是单一标量 |

**关键数据事实（本次实测，供适配性判定引用）**

| 事实 | 数值 | 对适配性的影响 |
|---|---|---|
| 附件 1 电价区间 | 0.3713–1.3952 元/kWh（全为正） | 支持 LP 的"充放电互斥由最优性自动保证"论证 |
| 附件 4 电价区间 | 0.0076–1.7936 元/kWh（全为正） | 同上；且无负电价 ⇒ 不存在"负价逼迫同时充放"的退化情形 |
| 附件 1 日内电价极差 | 1.0239 元/kWh | 套利空间存在 |
| 附件 4 日内电价极差 | 均值 1.1073，最大 1.4995 元/kWh | 波动电价下套利空间更大，但决策风险更高 |
| 日负载电量（典型日） | 111 025 kWh | 储能可用容量 9600 kWh 仅占 8.6%，套利幅度有限但非零 |
| 日光伏电量（典型日 / 全年） | 55 483 / 34 361–75 223 kWh | 光伏覆盖日负载 31%–68%，季节差异巨大 |
| 光伏峰值功率 | 10 216.2 kW（> 储能最大充电功率 5000 kW） | **弃光不可避免**，模型必须有弃光变量 |
| 光伏 − 负载最大净值 | 6 602.0 kW（> 5000 kW） | 同上，全年约 241 段（0.46%）必然弃光 |
| 负载 − 光伏最大净需求 | 6 687.7 kW | 缺电风险真实存在 |
| 附件 3 的 0:00 预报误差 | RMSE ≈ 563.7 kW，偏差 −27 kW（相对小时光伏均值约 24%） | 预报误差显著 ⇒ 随机/滚动方法有价值；也说明情景集可构造 |
| 结果期 | 2025-02-01 至 2025-12-31（334 天，1 月被排除） | 支持"1 月为预热期"的推断 |

## 7. 落地与论文写作建议

### 7.1 预处理

1. **统一时间轴**：144 段 × 10 min，$\Delta t=1/6$ h，端点标记（`0:00+1` = 24:00）；所有 kW → kWh 乘以 1/6。
2. **附件 3 降尺度**：24 整点 → 144 段；采用形状感知插值（用历史日内形状分配），保证小时均值守恒；按发布时刻做跨日拼接。对齐口径取"预报第 $k$ 小时 ↔ 实际区间 $[k-1,k)$"（该口径下 0:00 预报全年 RMSE ≈ 563.7 kW，优于错开一小时的 693.8 kW）。
3. **弃光变量**：显式引入 $Q_t$，可用光伏上限为 $\min(G_t,\ L_t+C_t^{\max}+D_t^{\text{used}})$。
4. **量纲校验**：容量 12000 kWh、功率 5000 kW、每时段上限 833.33 kWh——论文中必须显式写出换算，这是字典列出的 LP 首要禁忌（"量纲或单位不统一使约束失真"）。

### 7.2 训练 / 估计设计

| 模块 | 设计 |
|---|---|
| 问题 1 | 无估计，纯参数已知的优化 |
| 问题 2 情景集 | 1 月作为预热；2 月起，用**截至前一日的滚动窗口**估计光伏/负载残差分布；按"季节 × 阴晴类型"分层；用**块自助**保留日内相关性；k-means 削减至 $N$ 个情景 |
| 问题 3 情景树 | 按 4 个发布时刻分别估计各预见期的条件误差分布；分支因子控制在 3–5 |
| 问题 4 电价情景 | 对附件 4 的日内曲线做 k-means（形状 + 水平）；类内残差重抽样；**与光伏联合抽样**以保留相关性（如晴天正午光伏大发 + 电价偏低） |
| 样本划分 | 严格按时间顺序：训练集永远在验证集之前；1 月为预热，2–12 月为评估期；**禁止随机划分**（会破坏时间依赖，泄漏未来信息） |

### 7.5 论文必须报告的内容

1. **模型族的统一表述**：明确写出"四问共用同一能量平衡内核，问题 2 加情景维度、问题 3 加决策节点、问题 4 把电价随机化"。
2. **为什么不用启发式**：明确说明本题为线性凸问题，可用 LP 求全局最优，因此不采用 PSO/GA 作为主模型（若用了，必须报告与 LP 最优值的 gap）。
3. **为什么问题 1 不加 0-1 变量**：给出"电价恒正 ⇒ 同时充放非最优"的论证，并附事后检查 $\min(C_t,D_t)<10^{-6}$ 的证据。
4. **四项必须声明的口径**（见下节）：储能效率、问题 2 信息边界、日循环是否沿用、预报降尺度方法。
5. **敏感性分析**：$\eta$ 两套口径、情景数、$\Gamma$、缓冲分位数、跨日 SOC 终端处理。
6. **局限性**：线性效率模型未考虑充放电功率相关的效率衰减；未考虑电池循环寿命损耗；情景分布由一年数据估计，外推能力有限。
